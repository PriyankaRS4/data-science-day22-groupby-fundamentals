# GroupBy Fundamentals

## Description
Use Pandas groupby() to summarize numerical data across categories and groups.

## Objective
Understand grouping operations that are essential for exploratory data analysis.

## Tools
- Python
- Pandas
- Jupyter Notebook

## Deliverables
- At least five groupby examples
- Examples using sum, mean, count, minimum, and maximum
- A short interpretation of group-level results

## Hints / Mini Guide
- Start with df.groupby('column')
- Use aggregation functions after grouping
- Try grouping by more than one column

## Suggested Datasets
- Superstore Dataset
- Titanic Dataset

## Interview Questions
- What does groupby() do?
- What is aggregation?
- How can you group by multiple columns?
